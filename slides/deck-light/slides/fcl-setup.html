The managed route, start to finish. In the Fivetran dashboard there is a Context tab with a guided flow. Select the data in your warehouse to build from; optionally connect sources such as Jira, Gong or Google Drive; build, which parses the documents, indexes them for search and builds the context catalog; review the organization fingerprint it found; test questions in the playground; then install it in your AI client over Agent Context MCP. A build typically takes about a day. Embedding runs on your own model credentials, and parsing and cataloging run on Fivetran-managed models, so data residency matters: the preview is North America only. That is the shortcut. The rest of this talk is the long way, by hand, so you can see every step it automates.
